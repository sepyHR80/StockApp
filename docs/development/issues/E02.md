# [E02] Gate deployment and Android releases on CI

GitHub: https://github.com/sepyHR80/StockApp/issues/35

## Goal

Run required checks on main and deploy only after green checks; produce traceable Android artifacts.

## Scope

In scope: Run required checks on main and deploy only after green checks; produce traceable Android artifacts.

Out of scope: Automatic merges or unreviewed signing-key publication.

## Dependencies

https://github.com/sepyHR80/StockApp/issues/34, https://github.com/sepyHR80/StockApp/issues/9

## Deliverable

Implementation or documentation matching this scope, with updates to [development/workflow.md](https://github.com/sepyHR80/StockApp/blob/codex/architecture-foundation/docs/development/workflow.md).

## Acceptance criteria

- [ ] Failed required checks prevent release.
- [ ] Running API and APK versions map to a commit.
- [ ] A post-deploy smoke test detects a broken release.

## Verification and evidence

Deliberately fail a disposable-branch check; verify no deploy; inspect successful artifact metadata.

Attach the command, result, commit SHA and relevant redacted screenshots/reports to the PR. Future-stage commands apply after their implementation exists. Do not close this issue on documentation alone when its scope requires running software.

## Delivery

Phase E; future implementation backlog. Branch `codex/<issue-number>-<short-name>`; PR into `main`, with dependency on native UI PR #5 where relevant. No automatic merge.
