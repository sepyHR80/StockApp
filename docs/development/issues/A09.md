# [A09] Apply design changes with isolated Codex runs

GitHub: https://github.com/sepyHR80/StockApp/issues/14

## Goal

Run existing Codex CLI in a dedicated worktree, enforce UI-only changes, build/lint and install successful previews on a selected emulator.

## Scope

In scope: Run existing Codex CLI in a dedicated worktree, enforce UI-only changes, build/lint and install successful previews on a selected emulator.

Out of scope: Automatic push, merge, deploy or dependency changes.

## Dependencies

https://github.com/sepyHR80/StockApp/issues/13

## Deliverable

Implementation or documentation matching this scope, with updates to [design-sync.md](https://github.com/sepyHR80/StockApp/blob/codex/architecture-foundation/docs/design-sync.md).

## Acceptance criteria

- [ ] The listener starts paused, retains the newest design, and resumes after Penpot stops; assembly and lint run sequentially before the operator starts the preview emulator.

- [ ] Color, spacing and component-order edits produce a successful native preview.
- [ ] Manual edits, out-of-scope diffs and quota failures stop clearly.
- [ ] Ten runs/hour and one build-repair attempt per revision are enforced; restart does not overwrite work.
